# Atlas Studio — Land Survey Concept 03

A clean, map-first geospatial website concept aimed at engineering, development, architecture, construction, and land-survey clients.

## Features
- Responsive desktop, tablet, and mobile layout
- Interactive parcel control points
- Project map layer switching
- Boundary, topographic, subdivision, construction/as-built, and geospatial service presentation
- Interactive deliverable previews
- Local-only inquiry demo

## Preview
Open `index.html` directly in a browser.

## Deployment
This repository is intentionally **not connected to Netlify**, so changes here do not consume the Netlify credits being reserved for the existing live projects.

## Important
All parcel dimensions, coordinates, elevations, project names, and survey data are sample/demo information. Company identity, professional licenses, personnel, equipment, service coverage, and final claims must be verified before publishing this as a real client website.
